# نظام تحسين القص والتوزيع الأمثل
# Cutting Optimizer System

## نظرة عامة
نظام متكامل لإدارة مخزن المواد الخام وتحسين عمليات القص بطريقة ذكية مع دعم التوصيل والفضلات.

## المميزات الرئيسية

### 1. إدارة المخزن (Inventory Management)
- إدارة المواد الخام مع الأطوال القياسية والأسعار
- تتبع الفضلات (Offcuts) بحالة "متوفر" أو "تم الاستخدام"
- فلترة ذكية للفضلات حسب الحالة

### 2. مدخلات القص (Cutting Inputs)
- إدخال الأطوال والكميات المطلوبة
- تخصيص أسماء وألوان للقطع
- جداول منظمة وسهلة الإدارة

### 3. خوارزمية التحسين (Optimization Engine)
- **أولوية السحب الذكي**: البحث في الفضلات أولاً قبل استخدام المواد الخام
- **خوارزمية التوصيل**: دمج قطعتين كحد أقصى مع احتساب فاقد اللحام
- **احتساب سُمك القص**: خصم Kerf تلقائياً من كل عملية قص
- **توليد الفضلات**: تصنيف الفضلات الجديدة تلقائياً (صالحة/هدر)

### 4. النتائج البصرية (Visual Results)
- مخططات شريطية تفاعلية توضح توزيع القطع
- تمييز القطع الموصولة بخطوط متقطعة
- إحصائيات شاملة (نسبة الهدر، الكفاءة، التكلفة)
- زر تبديل العرض (مفصل/مختصر)

### 5. حماية المخزن (Transaction Safety)
- نظام تأكيد/إلغاء قبل تحديث المخزن
- سجل عمليات كامل (Audit Trail)
- تحديث تلقائي للمخزن عند التأكيد

## البنية التقنية

```
cutting_optimizer/
├── main.py                 # نقطة الدخول الرئيسية
├── requirements.txt        # المتطلبات
├── core/
│   ├── database.py        # إدارة قاعدة البيانات (SQLite)
│   └── optimizer.py       # محرك التحسين والخوارزميات
└── ui/
    ├── main_window.py     # النافذة الرئيسية والتنقل
    ├── inventory_window.py # واجهة المخزن
    ├── cutting_inputs_window.py # واجهة المدخلات
    └── results_window.py  # واجهة النتائج
```

## التشغيل

```bash
# تثبيت المتطلبات
pip install -r requirements.txt

# تشغيل البرنامج
python main.py
```
